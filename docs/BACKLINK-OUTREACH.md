# Backlink & Citation Outreach Kit — Veritas Worldwide

**Purpose:** Help journalists, researchers, librarians, and educators cite The Record with durable, primary-source-backed URLs.  
**Site:** https://veritasworldwide.com  
**Standard:** Google Search Central treats earned editorial links as quality signals when they come from relevant, trusted sources—never buy links or use PBNs.


---

## 4. Link hygiene (do / don’t)

**Do**

- Link to HTTPS canonical URLs only (`https://veritasworldwide.com/...`)
- Prefer deep links (chapter, profile, methodology) over homepage-only
- Mention archive pins / corpus JSON when the audience is technical

**Don’t**

- Buy links, guest-post farms, or reciprocal schemes
- Cloak affiliate or sponsored placements without disclosure
- Mass-email without personalization (spam risk + brand harm)

---

## 5. Monitoring checklist (ops)

1. Google Search Console → Links report (monthly)
2. Check referring domains for `/profile/*`, `/chapter/*`, `/israel-dossier`
3. Ensure new profiles appear in sitemap after deploy (image sitemap included)
4. Resubmit sitemap after large densify waves if GSC shows lag
